# Browser Demo — Asset Manifest

The reference HTML expects these relative paths:

| Path | Role |
|---|---|
| `assets/spring-valley.gif` | Spring / river valley environment sequence |
| `assets/azure-trench.gif` | Deep-sea environment sequence |
| `assets/ancient-reach.gif` | Ancient forest / volcanic region scene |
| `assets/blooming-den.gif` | Family / nesting scene |
| `assets/sky-isles.gif` | Floating highlands / aerial scene |

These GIFs were packaged in the local browser demo archive produced during the conversation. They are not yet committed to this repository. Add the original files under this folder before calling the browser prototype self-contained.

Do not replace these scene sequences with unrelated stock imagery. The prototype is for visual and interaction reference only; the animation clips are not per-individual skeletal animation and do not validate the production creature animation system.
